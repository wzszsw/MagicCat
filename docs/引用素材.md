# MagicCat 引用素材清单（来源/许可证追溯）

> 本文件用于记录 MagicCat 所依赖的**外部素材库**（图标等）的来源 GitHub 链接与许可，
> 便于日后追溯、升级或替换。**自绘**的图标不使用外部素材，无需记录。

## Devicon（数据库产品连接图标）

- **来源**：https://github.com/devicons/devicon
- **许可证**：MIT License（可自由使用、修改、商用；需保留版权与许可声明）
- **用途**：数据库产品连接图标/向导产品卡片
  - MySQL（`mysql-original`）、PostgreSQL（`postgresql-original`）、MariaDB（`mariadb-original`）
  - 目前仅接入这三个已支持产品；Oracle / SQL Server 等已在产品列表移除，暂未接入。
- **本地资产**：`magiccat/resources/logos/`（由 SVG 用 QtSvg 渲染为 16/32/64px PNG）
  - `mysql-16/32/64.png`、`postgresql-16/32/64.png`、`mariadb-16/32/64.png`
- **许可与商标声明**：同目录 `LICENSE.txt`（含完整 MIT 文本；logo 为其各自商标持有人所有）。
- **接入代码**：`magiccat/ui/icons.py` → `_logo_image()` / `_conn_by_provider()`。
- **重新生成**：下载 devicon SVG → QtSvg 渲染成多尺寸 PNG（生成脚本可参考 `.devdata/gen_logos.py` 的思路）。
- **打包**：PyInstaller 的 `datas` 已包含整个 `magiccat/resources`，打包时自动带入 `logos/`。

## 其它外部素材

- 目前暂无。其余图标均为 `magiccat/ui/icons.py` 里 Qt 自绘（无第三方版权）。
