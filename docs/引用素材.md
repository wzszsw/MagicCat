# MagicCat 引用素材清单（来源/许可证追溯）

> 本文件用于记录 MagicCat 所依赖的**外部素材库**（图标等）的来源 GitHub 链接与许可，
> 便于日后追溯、升级或替换。**自绘**的图标不使用外部素材，无需记录。

## Devicon（数据库产品连接图标）

- **来源**：https://github.com/devicons/devicon
- **许可证**：MIT License（可自由使用、修改、商用；需保留版权与许可声明）
- **用途**：数据库产品连接图标/向导产品卡片
  - MySQL（`mysql-original`）、PostgreSQL（`postgresql-original`）、MariaDB（`mariadb-original`）
  - GaussDB 使用单独的 Huawei 素材（见下文）；Oracle / SQL Server 等已在产品列表移除，暂未接入。
- **本地资产**：`magiccat/resources/logos/`（由 SVG 用 QtSvg 渲染为 16/32/64px PNG）
  - `mysql-16/32/64.png`、`postgresql-16/32/64.png`、`mariadb-16/32/64.png`
- **许可与商标声明**：同目录 `LICENSE.txt`（含完整 MIT 文本；logo 为其各自商标持有人所有）。
- **接入代码**：`magiccat/ui/icons.py` → `_logo_image()` / `_conn_by_provider()`。
- **重新生成**：下载 devicon SVG → QtSvg 渲染成多尺寸 PNG（生成脚本可参考 `.devdata/gen_logos.py` 的思路）。
- **打包**：PyInstaller 的 `datas` 已包含整个 `magiccat/resources`，打包时自动带入 `logos/`。

## 其它外部素材

- GaussDB 连接图标：参考用户提供的 Navicat 截图中的华为红底白色花瓣标识，
  使用 GitHub Simple Icons 的 Huawei SVG（https://github.com/simple-icons/simple-icons/blob/develop/icons/huawei.svg），
  由 QtSvg 直接渲染，不使用 QPainter 自绘品牌图形。Simple Icons 采用 CC0 1.0 Universal，
  许可文本见 `magiccat/resources/logos/SIMPLE_ICONS_LICENSE.md`。
- `gaussdbjdbc.jar`：用户本机提供的华为 JDBC 驱动（受版权约束），仅由「工具 → 环境」读取本地路径，
  不纳入 Git、Maven 依赖、PyInstaller 或其它发行包。
- database 图标：GitHub Tabler Icons 的 `database.svg`
  （https://github.com/tabler/tabler-icons，MIT License），许可文本见 `magiccat/resources/icons/TABLER_LICENSE`。
- schema / table 图标：GitHub Ant Design Icons 的 `deployment-unit.svg` / `table.svg`
  （https://github.com/ant-design/ant-design-icons，MIT License），许可文本见
  `magiccat/resources/icons/ANT_DESIGN_LICENSE`。
- 其余图标均为 `magiccat/ui/icons.py` 里 Qt 自绘（无第三方版权）。
